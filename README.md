# SoundWeave 声织 · 轻量音色编曲工作站

> 一个让人愿意打开、随手弹奏、探索声音，并把灵感完成为音乐的工作站。

**当前状态：v0.7.2，可运行的 Web 应用 + Windows 桌面 EXE**。5 类合成音源（电钢 / 钢琴 / 钢弦吉他 / 合成器与贝斯 / 鼓机）+ **4 套真实采样音源**（立式钢琴、钢弦吉他、电贝斯、原声鼓组）、64 个合成预设 + 4 个采样预设、48 个编曲块、3 首可编辑示例工程、多轨时间轴、钢琴卷帘与鼓步进、录制、调音台与效果、自动化、撤销重做、工程保存与自动恢复、MIDI 文件导入导出、Web MIDI（含延音踏板、弯音、触后、CC MIDI Learn）、WAV 音频导入与音频轨、WAV 混音与分轨导出、**回溯录制、五线谱只读视图与基于音阶的辅助和弦建议**。

## 1. 启动

### 1.1 环境要求

| 项目 | 要求 |
| --- | --- |
| 浏览器 | Chrome / Edge 等 Chromium 系浏览器（需要 AudioWorklet）。已实测 Windows + Chrome；Firefox、Safari 未验证 |
| Node.js | 20 或以上（仅开发、构建、打包、跑测试需要；已实测 Node 24 / npm 11）。交付物不需要 Node |
| 操作系统 | Windows（EXE 仅提供 win32-x64）；Web 版 Windows / macOS / Linux 均可；界面按桌面尺寸设计，未做移动端适配 |
| 网络 | 本地运行与 EXE 运行都不需要联网；没有第三方 CDN 或在线音源 |

### 1.2 桌面 EXE（免安装，直接双击）

产物在 `release/SoundWeave-win32-x64/`：

1. 双击其中的 **SoundWeave.exe** 即可运行，无需安装，也没有注册表写入。
2. **整个文件夹要一起拷贝**：EXE 依赖同目录下的运行库与 `resources/app.asar`，只拷 EXE 会打不开。
3. 首次运行可能被 Windows SmartScreen 拦下（未做代码签名）：点「更多信息」→「仍要运行」。
4. 关闭窗口即退出；不会残留后台进程。
5. 导出 WAV / 工程 / MIDI 时会弹出系统「另存为」窗口，默认目录为「文档」。

如遇启动异常，可带参数启动并收集自检结果（开发排查用）：

```powershell
.\release\SoundWeave-win32-x64\SoundWeave.exe --smoke-out .\work\smoke.json
```

### 1.3 开发模式启动

```powershell
npm install
npm run dev
```

终端会打印本地地址，浏览器打开 **http://127.0.0.1:5173** 即可。

> 浏览器规定音频必须由用户操作触发。首次进入页面时点一下「▶」或弹一个键，引擎才会启动；状态栏右侧出现 `48 kHz · 运行中 · AudioWorklet` 表示音频引擎已就绪。

### 1.4 生产构建与预览（交付网站用）

```powershell
npm run build      # 类型检查 + 构建，产物在 dist/
npm run preview    # 本地预览构建产物：http://127.0.0.1:4173
```

`dist/` 是纯静态文件，零运行时依赖，可直接放到任意静态服务器（Nginx、GitHub Pages、对象存储等）根目录。**不要用 `file://` 直接双击打开**——ES module 与 AudioWorklet 需要 http(s) 环境。

### 1.5 重新打包 EXE

```powershell
npm run exe        # 先 build，再打包到 release/SoundWeave-win32-x64/
npm run exe:smoke  # 自动化自检：启动 EXE → 播放 → 导出 WAV → 校验 8 项
```

打包由 `@electron/packager` 完成，只把 `dist/`、`electron/` 与 `package.json` 装进 asar，不进源码、测试与 `node_modules`。若 Electron 二进制下载超时，先设置镜像：

```powershell
$env:ELECTRON_MIRROR='https://npmmirror.com/mirrors/electron/'
```

## 2. 五分钟上手

1. **先载入示例**：左栏「示例」Tab → 选「夜航 Lo-fi」→ 点「载入工程」。载入会替换当前工程（未保存内容会丢失）。
2. **播放**：点顶栏「▶」或按空格。位置读数形如 `2.1`（第 2 小节第 1 拍）。
3. **换音色**：左栏「预设」Tab → 单击试听 → 双击应用到当前选中轨道（再单击另一个预设可做 A/B 对比）。
4. **插入编曲块**：切到「编曲块」Tab → 拖到时间轴任意轨道，或双击插入到播放头位置。
5. **改音符**：点一个片段，中央下方是它的钢琴卷帘（鼓轨自动变成步进网格），拖动/双击即可编辑。
6. **混音**：右栏调音台推子调音量，`M` 静音、`S` 独奏、`PAN` 声像、`REV` 混响发送。
7. **保存或导出**：顶栏「保存」写工程文件（`Ctrl+S` 同效），「导出 WAV」离线渲染实际工程并下载。

## 3. 界面分区

- **顶栏**：左侧运输（播放 / 暂停、停止、录制、BPM、循环开关与区间、节拍器、MIDI、位置）；右侧文件栏（新建 / 打开 / 保存、导入 MIDI / 导出 MIDI、导入 WAV、导出 WAV、分轨、撤销 / 重做、缩放、吸附）。
- **左栏 素材库**：预设 / 编曲块 / 示例 / 生成 四个 Tab，带搜索；预设页含「我的音色」分组与音色库导出 / 导入，编曲块页含「保存片段」「我的编曲块」与块库导出 / 导入，生成页可从风格预设生成一段完整 ambient 工程。
- **中央 时间轴**：按轨道分行显示片段与波形；上方标题栏显示 `n 轨 · n 片段 · BPM`。
- **中央下方 钢琴卷帘 / 鼓步进 / 五线谱**：显示当前选中片段的音符；标题栏右侧可在「卷帘 / 五线谱」之间切换，下方和弦条显示所选音阶的自然七和弦；标题栏显示片段名、起点、长度、音符数。
- **右栏 检查器**：轨道名、预设说明、宏旋钮、底层参数、FX 滑杆、MIDI 映射、自动化、片段操作、总线音量、保存音色。
- **右栏下方 调音台**：每轨竖向推子 + 立体电平表 + `M`/`S` + `PAN`/`REV` 小滑杆。
- **底部 键盘**：屏幕键盘 / 鼓打击垫，可点击演奏。
- **状态栏**：操作提示、MIDI 状态、引擎状态（采样率 · 运行中）。

## 4. 各项功能怎么用

### 4.1 音色与预设

- 内置 **68 个预设**：64 个程序化合成音色 + **4 个真实采样音源**（立式钢琴 KW、钢弦吉他 FSS、指弹电贝斯 YR、原声鼓组 Muldjord）。新建工程默认就是「钢琴 + 贝斯 + 鼓机」的采样组合。
- 单击预设 = 试听；双击 = 应用到当前选中轨道；再次单击另一预设 → 状态栏提示 A/B 对比。
- 合成音色的检查器宏旋钮与底层参数实时生效；采样音色不显示无效的合成参数，只保留轨道效果（音色低通 / 过载 / 合唱 / 音量 / 声像 / 发送）。
- 检查器「保存音色」把当前参数与效果存进「我的音色」（localStorage，刷新保留），可删除、导出 JSON、导入 JSON（同 ID 跳过）；采样音色保存时会保留采样库引用。
- 采样来源与授权见 [docs/samples.md](docs/samples.md)。

### 4.2 编曲块

- 拖到时间轴，或双击插入到播放头；插入后就是普通片段，音符可继续编辑。
- 选中片段后点编曲块页的「保存片段」，可把自己写的片段存成自定义块（起音归零、按片段长度裁剪），支持删除与 JSON 导出 / 导入。

### 4.3 时间轴编辑

- 滚轮平移，`Ctrl`+滚轮缩放，顶栏 `−`/`+` 也可缩放。
- 拖动片段移动、拖片段右缘改长度、双击空白处新建片段。
- 选中片段后可在检查器做移调、量化、复制、删除；`Delete` 删除选中片段。
- 吸附粒度由顶栏下拉选择（1/16 拍 ~ 1 拍）。
- 循环：勾选「循环」并填起止拍，播放到终点自动回绕。

### 4.4 钢琴卷帘与鼓步进

- 空白处拖拽框选；`Ctrl` / `Shift` + 点击追加选择；`Ctrl+A` 全选。
- `Ctrl+C` / `Ctrl+V` 复制粘贴到播放头（保留相对位置与力度）。
- 方向键微调选中音符（左右 1 个吸附步、上下 1 个半音）；`Shift` + 拖动音符改力度。
- 鼓轨自动切换为步进网格：点击加/删鼓点，`Shift` + 点击切换力度。
- 音频轨没有音符，卷帘会提示改用导入 WAV（片段在时间轴拖动、检查器调增益）。

### 4.5 录制与自动化

- 点「●」进入录制：会自动补一个片段并开始播放，随后在键盘上演奏即写入当前轨道。
- 检查器「自动化」可从参数 / 效果下拉新建 lane；曲线画布单击加点并吸附、拖动绘制、拖控制点改值、右键删点。播放时移动参数会写入已存在的 lane。

### 4.6 演奏输入

- 屏幕键盘点击、鼓轨打击垫点击。
- 电脑键盘：`Z–M` 与 `Q–P` 为白/黑键，`[` / `]` 换八度，`Shift` 为闷音奏法。
- MIDI 键盘：点顶栏 `MIDI` 授权 Web MIDI，状态栏显示设备数量与名称；支持延音踏板（CC64）、CC123 全部停音、弯音（±2 半音）、通道/复音触后。
- CC MIDI Learn：检查器每个参数/效果滑杆右侧 `L` 按钮进入学习态（状态栏提示、行高亮），转动控制器即建立映射，滑杆显示 `CCn` 徽标；「MIDI 映射」分区可逐条删除。

### 4.7 混音

- 调音台推子调轨道音量，`M` 静音、`S` 独奏，`PAN` 声像，`REV` 混响发送。
- 检查器 FX 区可调低通、过载、合唱、延迟发送；总线音量在检查器底部。

### 4.8 保存、自动保存与恢复

- **保存**：顶栏「保存」下载 `工程名.swproj.json`（内嵌音频素材 PCM），`Ctrl+S` 同效。
- **打开**：顶栏「打开」选择工程 JSON。
- **自动保存**：编辑后约 600 ms 写入浏览器 localStorage，刷新后自动恢复。为控制体积，自动保存**剥离音频 PCM**，只留元数据与峰值。
- 因此刷新后若仍有音频片段引用缺 PCM 的素材，状态栏会提示「已恢复自动保存；n 个音频素材缺少 PCM，请重新导入对应 WAV 后播放」。重新导入**同一个 WAV** 即可补回数据，状态栏显示「已恢复音频素材…」，**不会多出一段片段**。
- `beforeunload` 时也会写一次自动保存；点「新建」会替换当前工程。

### 4.9 导入 WAV 与音频轨

1. 点顶栏「导入 WAV」，选择 WAV 文件。
2. 首次导入会创建（或复用）一条「音频」轨，片段落在播放头最近的吸附点；与已有片段重叠时自动后移。
3. 时间轴按真实峰值绘制波形；双击音频轨会提示改用导入按钮。
4. 选中音频片段后，检查器「音频片段」可调 `片段增益`（0–2）与 `素材起点`，也可复制 / 删除；「音频素材」显示时长、采样率、声道，缺 PCM 时给出警告。

支持与限制：

- 支持 8/16/24/32 位 PCM、32/64 位浮点 WAV，单/双声道，任意采样率（内部按素材原生采样率重采样）。
- 不支持 20 位、64 位整数与压缩 WAV（ADPCM 等）；单个文件上限 64 MB，单个素材最长 300 秒。
- 音频轨没有录音、没有波形内裁切与淡入淡出曲线，也不经过音源的低通/过载/合唱；素材只跟随轨道音量、声像、混响与延迟发送。
- 实时播放与离线导出走同一条 DSP 路径。

### 4.10 MIDI 文件

- 「导入 MIDI」：支持 format 0/1、running status 与 tempo meta，按 program 猜测音源类型追加轨道。
- 「导出 MIDI」：format 1，PPQ 480。MIDI 是交换格式，不保存效果、自动化与音频素材。

### 4.11 导出

- 「导出 WAV」：离线渲染整首工程（含效果尾音）后下载 16-bit / 48 kHz 立体声 WAV，渲染完成前状态栏显示进度提示，期间不要重复点击。
- 「分轨」：逐轨离线渲染并分别下载，文件名含轨道序号与轨道名。

### 4.12 回溯录制（v0.7.0）

- 即使**没有**按下「●」，实时演奏（屏幕键盘、电脑键盘、MIDI 键盘）也会被记入一个滚动缓冲（最多 64 个音符，超出丢弃最早的）。
- 点顶栏「回溯」：把缓冲里的这些音符按吸附网格写回当前选中片段；没有合适片段时会先补一个录制片段，再写入。
- 写入后缓冲清空；状态栏提示写入了多少个音符。若缓冲为空或音符不在所选片段范围内，会给出提示而不写入。
- 起点按当前吸附粒度取整，时长按 1/16 拍取整，越界音符会被丢弃或裁到片段结尾。

### 4.13 五线谱视图（v0.7.0）

- 中央编辑区标题栏左侧的「卷帘 / 五线谱」按钮切换显示模式：**卷帘**为可编辑的钢琴卷帘（鼓轨为步进网格），**五线谱**为只读记谱显示。
- 五线谱按高音谱表绘制（E4–F5 五线，含上下加线），音高由 MIDI 音高换算为自然音名 + 临时升降号（默认升号拼写），并绘制符头与符干、左侧 C4 / C5 音名标注。
- 五线谱是**显示模式**，不是可编辑记谱器：不能在此视图里增删音符、设置调号/拍号/符尾与连音；要改音符请切回卷帘。
- 音频轨与鼓轨没有五线谱视图，切过去会提示并保持卷帘。

### 4.14 辅助和弦建议（v0.7.0）

- 中央编辑区标题栏下方新增「调 / 音阶」两个下拉框，可选 12 个调性中心音，以及 7 种七声音阶：大调、自然小调、多利亚、弗里几亚、利底亚、混合利底亚、和声小调。
- 右侧和弦条按所选音阶实时列出该音阶上的 7 个自然七和弦，形如 `I Cmaj7`、`ii Dm7`、`V7 G7`、`vii° Bm7♭5`，罗马级数与和弦符号同时显示。
- 播放或移动播放头时，会自动高亮与播放头附近一个拍内正在发声的音高最匹配的和弦（覆盖和弦音最多者；平手取低级别）。
- 单击和弦芯片即用当前选中轨道的音色试听该和弦。音频轨无法试听，会给出提示。
- 限制：只提供所选音阶上的**自然**和弦，不含次属和弦、转位、离调与替代进行；和声小调按自然七和弦拼写，不额外处理增三和弦的替代写法。

## 6. 兼容性

- 仅实测 Chromium 系（Windows + Chrome）。Firefox / Safari 未验证。
- 需要 AudioWorklet；需要 Web MIDI 时浏览器须支持并授予站点权限。
- 未做移动端布局适配，建议 1200 px 以上宽度。
- 已交付 Windows x64 免安装 EXE（Electron 45 + 内置 Chromium，见 §1.2）；未提供 macOS / Linux 安装包，也未提供 MSI/NSIS 安装程序。

## 7. 常见问题

| 现象 | 处理 |
| --- | --- |
| 打开后没有声音 | 先点「▶」或在键盘上弹一下（浏览器要求用户操作后才允许音频）；确认状态栏显示 `48 kHz · 运行中 · AudioWorklet` |
| 用一段时间后显示在播但没声音（v0.7.1 已修） | 升级到 v0.7.1：坏事件时间戳、NaN 力度/参数会污染长反馈链路导致永久静音，现已加数值守卫；Worklet 抛异常或节点失效会在下次播放前自动重建，AudioContext 被系统挂起会自动 `resume()`，状态栏会提示「音频引擎已自动恢复」。若仍无声，先看这条提示 |
| 播放中仍有声音但看不到波形 | 该音频素材在自动保存后缺 PCM：重新导入同一个 WAV 补回（不会新增片段） |
| 采样音色听起来又像合成音源 | 采样库未加载（常见于只拷了 `dist/assets` 而漏了 `dist/samples`，或 EXE 只拷了 exe）；整份 `release/SoundWeave-win32-x64/` 或 `dist/` 一起部署即可。加载失败时会自动回退合成音源，不会静音 |
| EXE 体积比上一版大很多 | v0.7.2 起 `resources/app.asar` 内含 `samples/`（55.9 MB 真实采样），属预期 |
| 点 `MIDI` 后提示未获得权限 | 在浏览器站点权限中允许 MIDI，或在系统弹窗中允许 |
| 导出的 WAV 与听到的不完全一致 | 导出为离线渲染，效果尾音会额外延长约 1.6 s；音质差异需人工试听确认 |
| 打开工程提示失败 | 仅支持本软件保存的 `.swproj.json`；外部 JSON 会被逐项校验并拒绝非法内容 |
| 自动保存丢失 / 浏览器提示空间不足 | 自动保存用 localStorage，大工程可能触及配额；请用「保存」下载工程文件 |
| 双击 EXE 无反应或被 SmartScreen 拦截 | 确认整个 `release/SoundWeave-win32-x64/` 文件夹完整（不能只拷 EXE）；未签名版本需点「更多信息」→「仍要运行」 |
| EXE 里 MIDI 键盘无响应 | EXE 只放行 MIDI 权限，设备本身仍需被 Windows 识别；可在 Web 版对照排查 |
| EXE 导出时没弹保存框 | 若带 `--smoke-out` 参数启动会走自检模式（自动保存到临时目录），正常双击启动才会弹「另存为」 |

## 8. 版本、素材来源与已知限制

**版本**：v0.7.2。版本要点：v0.2.2 播放与导出正确性；v0.3.0 音色与编辑体验；v0.3.1 自定义编曲块；v0.4.0 弯音 / 触后 / CC MIDI Learn；v0.5.0 WAV 音频导入与音频轨；v0.6.0 桌面 EXE（Windows x64 免安装）与自检脚本；v0.7.0 回溯录制、五线谱只读视图与辅助和弦建议；v0.7.1 修复长时间使用后无声并重新打包 EXE；**v0.7.2 引入真实采样音源**（立式钢琴 / 钢弦吉他 / 电贝斯 / 原声鼓组，共 55.9 MB 采样，授权均为可再分发）。

**素材来源**：编曲块、示例工程与 64 个合成预设均为本项目内程序化合成与手工编写；v0.7.2 的 4 套乐器采样来自 FreePats（CC0 / CC BY 4.0 / GPL+采样例外，均可再分发），逐项出处与处理方式见 [docs/samples.md](docs/samples.md)。

**已知限制（如实记录）**：

- 音频轨不支持录音与波形编辑（只能摆放、改素材起点与片段增益）；不支持 20 位 / 64 位整数 / 压缩 WAV。
- 采样音源是**单声道**、无离键采样，钢琴/吉他只有 2 个力度层；鼓组的拍手、沙锤与 `perc` 仍为合成。超出采样音域的音高会自动回退到合成音源。素材来源与授权见 [docs/samples.md](docs/samples.md)。
- 五线谱是**只读显示视图**：无调号/拍号/符尾分组/连音，也不能在五线谱中编辑音符；音频轨与鼓轨没有五线谱。
- 和弦建议只给所选音阶上的自然七和弦，不含次属、转位、离调与替代进行；调性与音阶不随工程保存。
- 回溯录制缓冲只存在于内存（最多 64 个音符），刷新或关闭页面即丢失；只记录实时演奏，不记录播放中的片段内容。
- 弯音固定 ±2 半音且作用于整轨；复音触后用通道压力近似；无 MPE 与逐音表达。
- 自动保存不保存音频 PCM，需重导入同一 WAV 重连；工程文件会内嵌 PCM，素材越多文件越大。
- 每轨上限 15 条（第 16 轨保留给预设试听）。
- 音质的**人耳验收尚未进行**：64 个预设与 3 首示例的实际听感、导出 WAV 的听感都需人工确认，不能视为已达标。
- 仅实测 Chromium（Windows）；未做移动端适配。
- EXE 仅 Windows x64 便携版：无安装包、无自动更新、未代码签名（体积约 357 MB，压缩包未提供）；macOS / Linux 未打包。
- 详细未验证项见 [docs/verification.md §9](docs/verification.md)。

## 9. 产品规划（历史目标，含未实现部分）

以下为项目立项时的产品目标与路线。已实现部分见 §1–§8；**尚未实现**的条目在文末「完成的判断」处明确标注。

### 9.1 产品定位

面向希望快速创作，同时愿意深入探索音色的个人音乐爱好者。无需先安装大量插件、下载庞大音源库，就能开始做音乐。

最终交付至少一种实际可运行的形态：

- **网站／Web 应用**：在浏览器中打开使用，可部署，也可按明确的本地启动说明运行。（已交付）
- **Windows EXE**：可安装或便携运行的桌面程序，包含运行所需依赖。（已交付：免安装便携版，`release/SoundWeave-win32-x64/`）

网站和 EXE 不要求首版同时完成。先完成一种可靠交付，再考虑另一种。

### 9.2 核心体验

1. 打开软件，马上试听并挑选一个喜欢的音色。
2. 用电脑键盘、屏幕键盘或兼容的 MIDI 键盘演奏。
3. 将和弦进行、旋律、贝斯或鼓循环拖入时间轴，形成作品骨架。
4. 在钢琴卷帘中修改音符，或录入自己的演奏。
5. 循环播放，调节音色、奏法和效果，把参数变化录入自动化。
6. 完成多轨编排、基础混音，保存工程并导出音频。

### 9.3 音色是核心资产

内置乐器：电钢琴（FM 双调制）、钢琴（非谐泛音）、钢弦吉他（Karplus-Strong 物理建模）、鼓机（分层合成）、合成器与贝斯（多振荡器 + 滤波）。

共建原则：数量必须建立在品质与实质差异之上；自然性来自力度对应的音色变化、合乎乐器规律的奏法、合理的起音与释音。

预设库已交付 64 个（电钢 8、吉他 6、钢琴/贝斯 8、合成贝斯 8、主音/拨弦 10、铺底/纹理 12、实验/音效 8、鼓组 4），支持收藏式自定义音色、分类、搜索与 A/B 比较。**逐个人耳验收尚未完成**。

### 9.4 编曲块

编曲块包含音符与表达信息，拖入工程后可以继续编辑，不是不可修改的音频循环。已交付 48 块（和弦 12、旋律 10、贝斯 8、鼓 12、填充/过渡 6）与 3 首可编辑示例工程，并支持把自写片段存为自定义块。

### 9.5 编曲、演奏与表达

已实现：多轨时间轴（添加/移动/复制/裁切/删除）、钢琴卷帘（输入、拖动、时长、力度、量化、吸附、框选、复制粘贴）、鼓步进、循环录制、自动化录制与曲线绘制、弯音与触后、踏板。

未实现：滑音与连奏、逐音表达与 MPE、摇摆与概率鼓点、演奏可视化（下落音符 / 滚动跟随）、MusicXML。**五线谱只读视图已于 v0.7.0 实现**（仅显示，不是可编辑记谱器）。

### 9.6 基础混音与文件

已实现：音量、声像、静音、独奏、电平、低通、饱和、合唱、延迟、混响、效果发送、主输出限幅；工程保存/打开/自动保存与恢复；MIDI 导入导出；WAV 音频导入；WAV 混音与分轨导出；自定义预设与编曲块的保存/导入/导出；缺失素材提示。

未实现：EQ、压缩、工程素材打包收集。

### 9.7 轻量的含义

启动快、默认界面清楚、常用操作少、基础素材精简、资源使用可测量；高级功能按需展开。轻量不等于用单个简单波形冒充所有乐器，也不等于省掉保存、撤销、错误提示和可靠导出。

### 9.9 后续可增加的功能

已实现（v0.7.0）：回溯录制、五线谱只读视图、基于所选音阶的实时和弦提示。详见 §4.12–§4.14。

仍**未实现**：

- 音色快照、参数间渐变、锁定部分参数的智能随机化。
- MIDI 控制器自定义曲线、MPE、微分音与自定义调律。
- 吉他指板与奏法编辑、更细致的扫弦和弦位系统。
- MusicXML 导入导出、可编辑记谱器（调号/拍号/符尾/连音）、可视化视频导出。
- 轨道冻结、可选音源包、第三方插件支持。
- 虚拟歌声：歌词、音素、音高与表情编辑。
- 和弦建议的进阶形态：次属和弦、转位与替代进行、按自动化/调性变化跟随。

### 9.10 完成的判断

用户在干净环境中启动交付物，选择音色，弹奏或拖入编曲块，编辑一段多轨音乐，保存并重开，然后导出与所听内容一致的音频。常用音色经过实际试听，素材来源可追溯，已知限制被如实记录。

当前达成情况：启动、演奏、编曲、保存重开与导出均已实现并有自动化与浏览器验证；Windows EXE 已打包并通过 8 项自动化自检（页面加载、引擎运行、播放推进、导出提示、无控制台报错、WAV 文件与 WAV 头合法）；**「常用音色经过实际试听」一项仍待人工完成**，这是发布前唯一未闭环的验收环节。详见 [docs/verification.md](docs/verification.md)。
